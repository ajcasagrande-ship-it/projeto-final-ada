# Projeto Final Ada — Análise de Acidentes de Trânsito (PRF)

Este projeto realiza uma análise exploratória dos dados de acidentes de trânsito registrados pela Polícia Rodoviária Federal (PRF) no ano de 2025. Nosso objetivo é compreender padrões, fatores associados e características dos acidentes ocorridos nas rodovias federais brasileiras.

## 📌 Perguntas da Análise

1. Quais tipos de acidentes foram mais frequentes em 2025 nas rodovias federais?
2. Quais estados registraram mais acidentes e vítimas (feridos e mortos)?
3. Existe relação entre condições climáticas e o número de acidentes?
4. Quais horários do dia concentram mais acidentes?
5. Rodovias de pista simples são mais letais do que pistas duplas?
